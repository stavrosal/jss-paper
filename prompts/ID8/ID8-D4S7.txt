We want a function that returns the total amount of items in

Assume there is a getName() getter in Product class. Also

class Store{

	List<Vegetable> vegetables;
	List<Fruit> fruits;
	List<Dairy> dairy;
	
	public void addVegetable(Vegetable item){
		this.vegetables.add(item);
	}
	
	public void addFruit(Fruit item){
		this.fruits.add(item);
	}
	
	public void addDairy(Dairy item){
		this.dairy.add(item);
	}
	
	public int getTotalItems(){
		int total = vegetables.size() + fruits.size() + dairy.size();
		
		return total;
	}
	
	
	public void printItemNames(){
		// Supposing that all Product classes have a getName() method
		for (Vegetable v : vegetables){
			System.out.println(v.getName());
		}
		
		for (Fruit f : fruits){
			System.out.println(f.getName());
		}
		
		for (Dairy d : dairy){
			System.out.println(d.getName());
		}
	}
}

import java.util.ArrayList;
import java.util.List;

// Abstract base class
abstract class Product {
    private String name;

    public Product(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}

// Concrete product types
class Vegetable extends Product {
    public Vegetable(String name) {
        super(name);
    }
}

class Fruit extends Product {
    public Fruit(String name) {
        super(name);
    }
}

class Dairy extends Product {
    public Dairy(String name) {
        super(name);
    }
}

// Store class
class Store {
    private List<Product> products;

    public Store() {
        this.products = new ArrayList<>();
    }

    public void addProduct(Product item) {
        products.add(item);
    }

    public int getTotalItems() {
        return products.size();
    }

    public void printItemNames() {
        for (Product p : products) {
            System.out.println(p.getName());
        }
    }
}

✅ Usage Example:

public class Main {
    public static void main(String[] args) {
        Store store = new Store();
        store.addProduct(new Vegetable("Carrot"));
        store.addProduct(new Fruit("Apple"));
        store.addProduct(new Dairy("Milk"));

        System.out.println("Total items in store: " + store.getTotalItems());
        store.printItemNames();
    }
}

✅ Benefits of This Design:

    Easier to extend: Add new product types without changing Store

    Cleaner code: No repetitive logic

    Flexible: You can add sorting, filtering, or categorization later without restructuring
