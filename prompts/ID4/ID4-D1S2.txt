✅ 5. Extension Mechanism
A simple extension mechanism:
Add a new Clothing Style Family
For example, Futuristic style.
Steps:
1.	Implement:

public class FuturisticShirt implements Shirt {...}
public class FuturisticPants implements Pants {...}

2.	Create the factory:

public class FuturisticFactory implements ClothesFactory {
    public Shirt createShirt() { return new FuturisticShirt(); }
    public Pants createPants() { return new FuturisticPants(); }
}

3.	Use it:

Shop futuristicShop = new Shop(new FuturisticFactory());

→ No existing code changes required → OCP compliant.
